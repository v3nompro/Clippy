# Changelog

## 0.1.0

Initial source release.

- Native AppKit clipboard picker with an Option-V global shortcut.
- Local history for text, rich text, images, URLs, and file references.
- Search, pinning, keyboard navigation, and deletion.
- Persistent SQLite storage with count and payload limits.
- Confidential clipboard filtering, Secure Input handling, and capture pause.
- Optional direct paste and launch at login.
- Permission status refresh while the picker is open.
- Standalone regression checks and macOS CI builds.
